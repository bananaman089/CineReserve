Как да подкараш CineReserve (накратко, без излишно философстване)

Това е система за кина — билети, прожекции, бар, касиер, админ. Работи на твоя компютър, не е в облака.

--------------------------------------------------
КАКВО ТИ ТРЯБВА
--------------------------------------------------

1) Java 17
   Не Java 8. Ако пише нещо за "unsupported class file version", значи си хванал старата Java.
   Най-лесно: Eclipse Temurin / Adoptium JDK 17.
   После си сложи JAVA_HOME към нея, примерно:
   C:\Users\ТВОЕТО_ИМЕ\AppData\Local\Programs\Eclipse Adoptium\jdk-17.xxxx-hotspot

2) MySQL
   Трябва да ти върти MySQL на localhost, порт 3306.
   Базата се казва cinema_db — приложението само си я прави, ако я няма.

3) Maven wrapper
   Не ти трябва да инсталираш Maven. В папката има mvnw.cmd, той се оправя.

--------------------------------------------------
НАСТРОЙКИ ЗА БАЗАТА
--------------------------------------------------

Отвори:
src\main\resources\application.properties

Там пише потребител и парола за MySQL. Сложи СИ своите, не моите.

Първоначално е нещо от сорта:
spring.datasource.username=root
spring.datasource.password=тук-си-писваш-паролата

Ако MySQL не върви или паролата е грешна, приложението ще гръмне още на старта. Нормално е, оправи връзката и пробвай пак.

--------------------------------------------------
КАК СЕ ПУСКА
--------------------------------------------------

1. Отвори папката на проекта:
   ticket-system\ticket-system

2. В PowerShell (важно: с Java 17):

   $env:JAVA_HOME = "ПЪТЯТ_КЪМ_JDK_17"
   $env:Path = "$env:JAVA_HOME\bin;" + $env:Path
   .\mvnw.cmd spring-boot:run

3. Чакаш да излезе нещо като:
   Started TicketSystemApplication
   Tomcat started on port 8080

4. Отваряш браузъра:
   http://localhost:8080

Ако порт 8080 е зает, значи вече някой сървър седи там. Спри го и пусни наново.

Първият път Maven ще си свали купчини неща. Иска интернет и малко търпение.

--------------------------------------------------
С КАКВО ДА ВЛЕЗЕШ
--------------------------------------------------

При първо пускане си прави тези акаунти, ако ги няма:

админ     →  admin     /  admin123
касиер    →  cashier   /  cashier123
клиент    →  client    /  client123

Админът прави кина, зали, филми, прожекции, хора.
Касиерът продава билети и пуканки.
Клиентът си купува билети.

--------------------------------------------------
АКО НЕЩО НЕ РАБОТИ
--------------------------------------------------

- "Port 8080 was already in use"
  Спри старото пускане и пробвай пак.

- Гърми на MySQL / Access denied
  Провери дали MySQL е пуснат и дали паролата в application.properties е вярна.

- Компилира с Java 8
  JAVA_HOME не сочи към 17. Оправи го и после пак .\mvnw.cmd spring-boot:run

- Страницата е бяла / стари бутони
  Направи hard refresh в браузъра (Ctrl + F5).

Готово. Ако стигнеш до логин екрана, значи си го подкарал.
